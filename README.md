# In-Context Learning and Prompt Engineering with LangChain

This project demonstrates practical applications of prompt engineering techniques using large language models (LLMs) via IBM Watsonx and LangChain.

## 🚀 Overview

The assignment explores how different prompting strategies affect LLM behavior, including:

* Zero-shot prompting
* Few-shot prompting
* Role-based prompting
* Prompt templates using LangChain

## 🧪 Tasks Implemented

* Text classification
* Sentiment analysis
* Summarization
* Keyword extraction
* Review analysis using chains

## 🛠️ Technologies Used

* Python
* LangChain
* IBM Watsonx AI
* LLMs (Granite / Mistral models)

## 📂 Project Structure

* `notebooks/` → Jupyter notebook containing full solution
* `requirements.txt` → dependencies

## ▶️ How to Run

1. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
2. Set your IBM Watsonx credentials
3. Run the notebook

## 📌 Notes

* API keys are not included for security reasons
* Model used: `ibm/granite-3-8b-instruct`

## 🎯 Learning Outcome

This project builds intuition on how prompt design impacts LLM performance and demonstrates practical use of LangChain for structured prompting workflows.
